# GitHub source and distribution snapshot

Published repository: https://github.com/Geruyang/MapToDoList

The existing Geruyang/waypoint-support repository was renamed on 2026-10-19. Main retains its earlier website history and now contains the complete iOS source, Xcode project, tests, configuration, scripts, development/release reports, selected release screenshots, and all three available signed distribution builds (2, 3, 4).

The current source matches all 48 entries of the Build 4 frozen-product-inputs manifest. No new application build or signing operation was performed for this GitHub publication. The signed IPA files are byte-identical to the recorded distribution artifacts.

Build 4 is the latest candidate. The last stored Apple receipt is the 2026-10-12 submission, not evidence of subsequent approval or publication. Build 2/3 are historical, superseded candidates.

Distribution files are under distribution/. Each build contains its original IPA, a complete xcarchive ZIP with dSYMs and signing metadata, and export records. SHA256SUMS and manifest.json record content integrity. See distribution/README.md.

Original multi-gigabyte xcresult packages, test videos, unreviewed device screenshots, build intermediates and secrets remain local. Their absence does not omit application source. The repository includes human-readable testing reports, selected machine-readable final summaries and curated release screenshots instead.

Root index.html, style.css, privacy/, terms/ and .nojekyll are retained for GitHub Pages. The renamed repository's Pages URL is https://geruyang.github.io/MapToDoList/. The frozen Build 4 AppLinks still uses the historical waypoint-support URLs; repository renaming does not change an already signed binary.
