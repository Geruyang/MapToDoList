# Waypoint Implementation Plan

**Goal:** 可构建可运行的原生地图待办 iOS App，覆盖用户七项功能。
**Architecture:** 主会话单写Core/App/工程配置，功能目录独立所有权。共享TaskItem与TaskStore契约，服务与界面分离，测试者独立验证集成版本。
**Tech Stack:** Swift5 mode / SwiftUI / iOS17+ / MapKit / UserNotifications / WeatherKit / StoreKit2 / Keychain / XCTest / XcodeGen。
**Spec:** ../specs/2026-10-11-waypoint-design.md
**Execution:** 用户已选择原生10子agent并行分工，主会话统一技术裁决及集成。

## Global Constraints
最低iOS17；禁止虚构天气、购买、模型名、测试结果。真实密钥不进源码日志。仅编辑分配目录。所有接口见 ../../design/INTERFACES.md。
## Review Focus
- 日期边界、夏令时与中文换行在导出/通知中正确处理。
- 编辑/删除/完成后通知不得残留；超过系统上限明确反馈。
- 不可达路线、时间冲突和远期天气不得表现为可行计划。
- 未认证购买、撤销和过期不得保持付费权限。
- 文件损坏/权限拒绝/网络失败不得静默丢数据或假成功。

## Tasks
- [ ] Core (主会话): TaskItem/TaskStore，原子存储及损坏保护单测；App生命周期协调通知与订阅；XcodeGen工程、Info.plist及capability声明。
- [ ] 地图 (map_tasks): MapScreen/TaskEditorView，搜索与选点，创建编辑删除完成与导航。验证空标题/坐标/时长边界和持久化。
- [ ] 提醒 (reminders): ReminderService/ReminderSettingsView，权限+同步+取消+容量策略；测试过去时间/已完成过滤和ID稳定。
- [ ] 导出 (export): ExportView，日期过滤+文本/MD/ICS，测试终日/跨区/转义/UTF8行折叠。
- [ ] 规划与AI (planning_ai): PlanningView/AISettingsView，本地可测试算法+真实ETA+WeatherSnapshot；固定不移动、窗口冲突测试；5家适配、Keychain与刷新/自定义模型，官方来源留档。
- [ ] 天气 (weather): WeatherProvider/WeatherCardView，当前/指定时刻数据、缓存与归属，测试预报时间范围和降雨缓冲；服务失败清楚呈现。
- [ ] UI (ui_implementation): RootView/TodayView/SettingsView/Theme，按 UI-SPEC 实现；完整空态/暗色/权限文案和可访问性ID。
- [ ] 订阅 (subscriptions): SubscriptionStore/SubscriptionView，真实权益+监听+恢复+StoreKit配置。测试周期/撤销状态和资格展示，生产配置文档。
- [ ] 设计 (ui_design): UI-SPEC，先交tokens和布局给实现者，再验证最终截图。
- [ ] 模拟器 (simulator_tests): 完整矩阵、XCUITest、截图、原始日志；只读产品并提出问题，修复归原作者。
- [ ] 真机 (device_tests): 可连接/签名环境、完整真机矩阵及实际安装验证，独立源码审查；缺凭证的测试明确NOT_RUN。

## Integration sequence
1. 主会话创建共享契约和Core，派工7实现模块，设计与测试提前并行。
2. 所有功能初稿后 xcodegen generate，xcodebuild build/test，逐项修复编译与逻辑问题。
3. 模拟器测试者跑交互，真机测试者检查精确候选，主会话修复集成问题。
4. 受影响检查重跑；记录版本与真实状态；交付工程与报告，未满足发行条件保留明确清单。
