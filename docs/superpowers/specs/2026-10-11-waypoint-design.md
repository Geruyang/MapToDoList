# 行迹 Waypoint 产品与技术方案

## 目标与授权
用户要求开发完整原生 iOS 地图待办 app，并明确授权主会话设计、技术裁决、指挥及并行实现。七个功能实现者 GPT-6.1-sol low，专门 UI 设计者和模拟器/真机测试者 GPT-6.1-sol high。主会话负责工程、共享模型、持久化、集成与验收。当前目录空，Xcode26.6可用。无需重复请求已给定的开发授权；商业发布、真实购买和账户后台更改不在本次执行范围。

## 技术方案及取舍
采用 SwiftUI + MapKit + Codable 原子文件存储 + UserNotifications + WeatherKit + StoreKit2 + Keychain，最低iOS17。原生方案能直接利用系统地图、通知、分享和订阅；Flutter增加桥接成本；Web不能满足可靠iOS本地通知与原生订阅体验。首版本地优先，不建立账号/后端、不强加云同步，AI由用户自带API Key并逐次主动发起请求。

## 七项功能
1. 地图搜索、点击选点、查看/编辑事项，时间、时长、地点、备注、完成状态，本机持久化，打开Apple地图导航。无定位权限仍可搜索/选点。
2. 提前0/5/15/30/60分钟等本地通知，声音/静音/时效模式；iOS设置决定最终声音/横幅表现，不能承诺任意振动或绕过专注模式。编辑完成删除同步撤销；在系统数量限制内安排最近事项并提示余量。
3. 自选起止日期，地点/当地时间/备注完整输出，纯文本及Markdown复制、ICS分享，结束日期包含整天，跨时区与特殊字符可解析。读出导出不因订阅过期阻断。
4. 固定事项不可自动改时；灵活事项具有最早/最晚窗口，按路程和可用时间安排；MapKit路程估计、天气缓冲和冲突风险可解释，无路况数据时明确降级。AI输入最小化并披露发送内容，支持GLM/Qwen/DeepSeek/OpenAI/Gemini，模型官方核验、刷新与自定义，Keychain安全存储；AI建议须预览确认，不直接覆盖时间。
5. 所选地点当前天气及规划时间天气，Apple WeatherKit归属展示；过远日期、网络、权限/签名错误如实呈现，不造天气；数据有缓存与时间标注。WeatherKit发行需开发者能力开通。
6. 奶白/墨绿/珊瑚色，地图主舞台，今日时间线，规划页，设置页；中文优先，暗色/动态字体/VoiceOver和44pt触控目标。UI全状态详见设计者的UI-SPEC。
7. 年订阅USD9.90，App Store introductory offer七天免费试用，仅对符合资格账户；价格以StoreKit本地化Product为准。验证签名交易、恢复、撤销过期；试用激活需系统购买确认。历史读出/导出保留。StoreKit本地测试与生产权益区分，不伪造已开通。发行前核实App Store Connect实际可选价格点及配置。

## 数据与边界
TaskItem含稳定UUID、标题备注、坐标地点、绝对时间及地点时区、时长、灵活窗口、提醒提前量模式、完成状态和创建时间。详情见 INTERFACES.md。保存采用原子写入和数据保护；损坏文件不静默覆盖；无外部秘钥被读取或上传。AI仅发送用户选择的事项，不能把模型编造的天气/路况当实际数据。

## 验收
模块逻辑单测、完整模拟器构建、XCUITest覆盖地图/创建编辑/持久化/导出/设置/规划，真机安装启动与设备特有能力验证。联网服务、后台通知、StoreKit sandbox、模型Key若缺环境则单列NOT_RUN/BLOCKED，不能等价视为通过。测试者独立审查精确候选；功能覆盖矩阵逐项列证据。最终交付Xcode工程、源码、设计、配置指南、测试报告及已知限制；不执行App Store发布。
