## 未覆盖边界

- 模拟器无法证明真机 GPS、电量、真实通知投递可靠性和 App Store 服务端完整生命周期；如只用本地 StoreKit 配置，结论仅限本地交易环境。
- 密钥安全的 UI 行为不能证明网络传输/内存全部安全；容器/日志检查与独立实现观察分别提供证据。
- 地图、路况、天气与 AI 外部服务须记录联网条件、来源和日期；无效密钥场景不能替代每家真实 API 成功验证。
