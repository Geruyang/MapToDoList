# Waypoint support website source

This directory contains the static support, privacy and terms website for Waypoint by Ge Ruyang. The deployed copies also live at the repository root so GitHub Pages can serve them from the main branch.

The repository was renamed from Geruyang/waypoint-support to Geruyang/MapToDoList on 2026-10-19 and now includes the iOS application source and signed distribution snapshots. The new Pages URL is https://geruyang.github.io/MapToDoList/.

The frozen Build 4 application still references the historical waypoint-support support URLs; its source and signed artifacts are retained unchanged for reproducibility. Legacy website compatibility is managed separately from the signed app snapshot.
